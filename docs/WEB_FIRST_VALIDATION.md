## 行为约束

- 原生文字提交只有新出现的网页成功提示和帖子链接同时匹配时才确认成功。目前识别英文和简体、繁体中文提示；其他反馈进入结果待确认。
- 提交意图在点击网页按钮前保存；结果未知时保留草稿并阻止重复提交，用户核实未发布后才可解除。
- 当前账号无法从网页确认时，不恢复账号草稿，也不显示原生发帖入口；保留网页导航。
- 转入完整网页编辑器后，原生文字草稿在成功移交时清除；网页内容不双向同步，关闭时提示未发送内容可能丢失。
- 默认模式暂保留既有浏览器标识，原始网页模式采用 ArkWeb 默认标识。移除了永久在线覆盖和注册流程的自动桌面标识切换。
- 本地通知能力不代表具备 X 后台推送。
